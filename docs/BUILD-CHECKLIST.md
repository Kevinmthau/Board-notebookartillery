# Build checklist

- [x] Copy exact Studio starter, install vendored SDK, and install verified Bloogs model.
- [x] Record approved plan and mint permanent app identity.
- [ ] Players can place real cannons and bind two roster seats.
- [ ] Players can rotate to aim, set power, and intentionally fire.
- [ ] Wind, flight, hit, miss, and turn rules work.
- [ ] Three hits end a match; one shared choice starts the next.
- [ ] Computer opponent uses the same shot rules and is selected from the roster.
- [ ] Browser supports the full game without physical pieces.
- [ ] Piece hold, move, rotate, lift, duplicate glyphs, blink, and pause tests pass.
- [ ] Colorful world, canonical setup art, effects, help, and seat HUDs are integrated.
- [ ] No digital cannon appears during play.
- [ ] Automated tests and Board package pass.
- [ ] Browser title, setup, shot, damage, result, rematch, and pause checks pass.
- [ ] Real Board and human playtest: requires hardware and players; unverified.
