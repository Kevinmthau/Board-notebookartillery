# Build checklist

- [x] Copy exact Studio starter, install vendored SDK, and install verified Bloogs model.
- [x] Record approved plan and mint permanent app identity.
- [x] Players can place real cannons and bind two roster seats.
- [x] Players can rotate to aim, set power, and intentionally fire.
- [x] Wind, flight, hit, miss, and turn rules work.
- [x] Three hits end a match; one shared choice starts the next.
- [x] Computer opponent uses the same shot rules and is selected from the roster.
- [x] Browser supports the full game without physical pieces.
- [x] Piece hold, move, rotate, lift, duplicate glyphs, blink, and pause tests pass.
- [x] Colorful world, canonical setup art, effects, help, and seat HUDs are integrated.
- [x] No digital cannon appears during play.
- [x] Automated tests and Board package pass.
- [x] Browser title, setup, shot, damage, result, rematch, and pause checks pass.
- [ ] Real Board and human playtest: requires hardware and players; unverified.
